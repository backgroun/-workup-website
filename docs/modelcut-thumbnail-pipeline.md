# 모델컷 썸네일 생성 파이프라인 — 상의(Tops) 규칙

누끼컷(옷만 있는 배경 제거 이미지)을 **정돈된 자세의 모델컷**으로 변환해
**1600×1600** 카탈로그 썸네일로 만드는 재사용 워크플로우. (출력 사이즈는 `THUMB_SIZE` 환경변수로 변경, 기본 1600)

> 🟦 **적용 범위 = 상의(tops)** — 티셔츠·셔츠·니트·자켓·베스트·아우터 등 윗옷.
> 아래의 자세·프레이밍·크롭(발끝 전신 생성 → 손 아래선 크롭 → 반신/전신)은 **상의 전용**이다.
> **하의·세트는 규칙이 다르다** → [카테고리별 규칙](#카테고리별-규칙-상의--하의--세트) 참고.

- **입력**: 누끼컷 (깔끔한 흰/단색 배경의 제품 단독 사진)
- **출력**: 1600×1600 PNG · **투명 배경(권장)** 또는 `#EDEDED` · 모델이 제품 착용 · 동일 자세/프레이밍
- **반신은 전신에서 크롭**: 반신을 따로 생성하면 손이 잘리기 쉬워, **전신을 받아서 상단을 크롭해 반신으로 사용**한다. 이를 위해 생성은 **4k 네이티브**로 하고 고해상도 소스(`full_src.png`)를 함께 저장 → 크롭해 키워도 선명
- **검증 사례**: 멀티포켓 메쉬 베스트(`PUB-1780496879419`) — 포켓·지퍼·초록 라벨까지 충실 보존 확인

> 💡 **투명 출력 권장 이유**: AI 생성물은 배경 회색이 매번 미세하게 달라진다.
> 배경을 제거해 투명 PNG로 내보내면 배경 불일치가 사라지고, 필요 시 합성 배경을
> 한 번에 통일할 수 있다.

> ⚠️ 이 파이프라인은 **실제 제품을 AI로 재생성**한다. 디테일 많은 옷은 미세 왜곡
> 가능성이 있으므로 3단계 QC를 반드시 거친다.

## 🔴 배색 필수 규칙 (MUST)

**강조하는 제품이 가장 잘 보이도록 배색한다. 필수 사항이다.**

- 강조 제품(상의든 하의든)과 **비슷한 색 계열로 나머지 의상을 매치하지 않는다.**
- 나머지 의상은 제품과 **대비되는 색**으로 골라 제품이 도드라지게 한다.
- **고정색 아님 — 제품마다 어울리는 대비색을 선택한다** (무조건 베이지 ❌ → 제품 색·톤에 맞는 대비색 ✅).
- 예시:
  - **검정 상의** 강조 → 하의 **베이지/밝은 톤** (JK423 확정). 어두운·검정 하의 금지.
  - **밝은 상의** 강조 → 하의 **어두운 톤**
  - **하의 강조** → 상의를 대비색으로
- 신발·배경도 제품을 가리지 않는 무채색/대비 톤으로.

> 이유: 제품이 같은 색 옷에 묻히면 카탈로그에서 형태·디테일이 안 보여 정보 전달 실패.
> 프롬프트에 매번 "featured product is [색] → choose a contrasting color that suits this
> product, do NOT use [같은 계열]" 지시를 명시한다.

## 카테고리별 규칙 (상의 / 하의 / 세트)

카테고리마다 **무엇을 강조하고 어디를 크롭할지**가 다르다. 같은 프레이밍을 쓰면 안 된다.

| 카테고리 | 강조 부위 | 크롭/프레이밍 | 상태 |
|----------|-----------|----------------|------|
| **상의(tops)** | 상반신·윗옷 | 발끝 전신 생성 → **손 아래선까지 크롭(반신)** + 전신 | ✅ 이 문서 |
| **하의(bottoms)** | 하반신·바지/스커트 | 발끝 전신 생성 → **하반신 크롭(상21·좌28·우27)**. 상의는 대비/조합색 다양하게, 신발 디자인 다양하게 | ✅ 2026-06-30 |
| **세트(set)** | 전체 코디 | 발끝 전신 그대로 (상하 모두 보이게) | ⏳ 규칙 미정 |

> 세트는 추후 정의. 아래 스펙·프롬프트·크롭 수치는 **상의 기준**이다.

### 하의(bottoms) 규칙 (2026-06-30 확정)

- **프레이밍**: 발끝 전신 생성 → 카탈로그 썸네일은 **하반신 크롭**(상의 밑단~발끝). 여백 **상 21% · 좌 28% · 우 27%**. 하의가 화면의 주인공.
- **상의**: 하의가 강조 제품이므로 상의는 **대비/조합되는 색**으로, **매번 다양하게**(흰색 고정 ❌ — 하의 색에 맞춰 어울리는 대비색 선택).
- **신발**: **디자인을 다양하게**(스니커즈·로퍼 등, 흰 운동화 고정 ❌).
- **포즈**: 다리·바지가 잘 보이게 정면 차렷, 발 약간 벌려 드레이프 자연스럽게. 1·2번 같은 자세 랜덤 무방.
- 저장: 상의처럼 `full_src.png`(4k 투명) 1개. (가이드 샘플: `상품/_하의가이드/model/full_src.png`)

## 자세·모델·배경 스펙 (상의 기준, 고정)

모든 상의 모델컷이 동일하게 보이도록 아래를 고정한다.

- **모델: 한국인 20–30대 남성 또는 여성, 호감형 얼굴, 부드러운 표정.** (제품 성격에 맞게 선택)
- 정면, 차렷에 가까운 정돈된 자세, 양팔 자연스럽게 내림, 어깨 수평, 고개 살짝 측면
- **전신(머리~발)으로 생성** — 타이트 상체컷은 AI가 손을 하단에서 자른다(아래 참고). 팔·손은 절대 잘리면 안 됨.
- 밝은 회색 무배경, 부드럽고 그림자 없는 균일 조명
- 디테일 적은 옷은 흰 티 위에, 아우터/베스트는 흰 티 레이어드

> ⚠️ **손 잘림 주의**: Nano Banana는 머리~허벅지 표준 크롭을 선호해서, 팔을 내린
> 자세에선 손이 프레임 하단 경계에 걸려 잘린다. 크롭 지시를 강화해도 반복됨.
> **해결: 전신으로 생성한 뒤, 배경 제거 후 "손 아래선"까지 세로로 잘라서 프레이밍**한다.

## 1단계 — AI 모델컷 생성 (magnific)

| 항목 | 값 |
|------|-----|
| 도구 | magnific `images_generate` |
| 모델(mode) | `imagen-nano-banana-2` (Google Nano Banana Pro — product/brand 충실도 최상) |
| aspectRatio | `1:1` |
| resolution | `4k` (반신 크롭 선명도 확보) |
| references | 누끼 이미지를 `creations_upload_image`로 올린 뒤 `{type:"image", identifier:"..."}` |
| count | 2 (가장 정확한 컷 선택) |

### 프롬프트 템플릿 (전신 · 한국인)

옷 종류에 따라 **[ ] 부분만** 교체한다. 디테일 보존 + 전신 프레이밍 지시는 그대로 유지.

```
A Korean [man/woman] in [his/her] late 20s with a friendly, likeable, attractive
face and a soft, gentle, relaxed expression. [He/She] wears the EXACT [제품 설명,
예: black multi-pocket mesh utility vest] shown in the reference image [over a
plain white t-shirt with dark trousers / 등]. Preserve the garment with absolute
fidelity: keep every pocket and its exact position and count, all zippers and
zipper pulls, [그 외 핵심 디테일]. Do not add, remove, recolor, or rearrange any detail.

This is a FULL-BODY standing studio shot: the ENTIRE body is visible from the top
of the head all the way down to the feet/shoes, with empty floor space below.
Calm tidy symmetric pose, facing forward, shoulders level, head slightly turned,
both arms hanging relaxed at the sides with both hands fully visible beside the
thighs. The whole figure (head, both hands, legs, feet) is completely inside the
frame and centered, nothing cropped at any edge.

Clean seamless light-gray studio background (#ededed), no visible horizon line.
Soft, even, shadowless studio lighting. Korean e-commerce catalog full-length
product photography. Photorealistic, sharp focus on the garment details.
```
- 설정: mode=`imagen-nano-banana-2`, aspectRatio=`1:1`, resolution=`4k`, count=2. (4k=반신 크롭 시 선명도 확보. 멀티앵글 레퍼런스로 충실도↑)
- 배경은 어차피 다음 단계에서 제거하므로 회색 미세 차이는 무시.

## 3단계 — 손 아래선 크롭 → 1600×1600 프레이밍

전신 컷아웃을 그대로 프레이밍하면 모델이 작게 들어간다(전신이 정사각형에 들어가
좌우 여백 ↑). **손 바로 아래선까지 세로로 잘라** 베스트를 키우되 손은 보존한다.

```bash
# (권장) 손 아래선까지 세로 크롭 — 발끝까지 전신 컷 기준 높이의 약 0.55~0.60 지점
#   sharp extract 로 top=0, height=원본H*0.58 정도. 정확한 선은 손 위치 보고 조정.
#   (머리~무릎 컷이면 ~0.72. 발끝 전신일수록 손이 위에 잡혀 더 낮게 자른다.)

# 프레이밍 → 1600×1600 (THUMB_SIZE 로 사이즈 변경 가능)
node scripts/thumbnail-frame.mjs <컷아웃.png> <출력.png> [width|height] [transparent]
```

> ✅ **발끝까지 전신 생성 권장**: 발끝까지 생성하면 손이 프레임 상대적으로 위쪽에
> 잡혀, 타이트 크롭해도 손 보존 + 좌우 여백 ≈26%(가이드 25/27 일치)가 동시에 된다.
> 머리~무릎 컷보다 결과가 좋다.

- 기본 `width` 모드 **권장**. 4번째 인자 `transparent` 주면 **투명 배경**, 생략 시 `#EDEDED`.
- `sharp` 필요(이미 프로젝트 의존성에 포함).
- 세로로 긴 컷(전신·손아래크롭)은 높이 상한(90%) 가드가 걸려 좌우 여백이 25/27보다
  넓어질 수 있다 — **손 보존을 우선**한 결과이며 정상이다. 더 타이트하게는 포토샵에서 조정.

### 프레이밍 규칙과 가이드 충돌 (중요)

가이드 여백(상23 / 하18 / 좌25 / 우27, 960px 기준)은 **서 있는 모델 체형
(바운딩박스 비율 ≈0.56)에선 세로·가로를 동시에 못 맞춘다.**

| 모드 | 기준 | 결과 | 비고 |
|------|------|------|------|
| `width` (권장) | 좌25 / 우27 고정 | 모델이 프레임을 꽉 채움, 세로 여백 ≈7% 자동 | **레퍼런스 룩과 일치** |
| `height` | 상23 / 하18 고정 | 세로는 정확하나 좌우 ≈33% → 모델이 작고 허전 | 비권장 |

> 허용 오차 ±3% 합의 기준. `width` 모드는 좌우를 가이드대로 정확히 맞추고,
> 세로 여백은 가운데 정렬로 흡수한다 → 모든 모델이 동일한 크기로 정렬되어
> 카탈로그 행이 깔끔하다.

## 자동 저장 (반신 + 전신 한 번에)

전신 투명 컷아웃 한 장만 넣으면 4종을 만들어 제품 폴더에 자동 저장한다.

```bash
node scripts/save-modelcut.mjs <제품ID> <전신컷아웃.png> [반신크롭비율=0.58]
```

**저장 위치:** `D:\WORK_DATA\2026_workup_website\generated\<제품ID>\`
(`generated/`는 `.gitignore` 처리되어 GitHub로 push되지 않는다 — 용량 안전)

| 파일 | 내용 |
|------|------|
| `full_src.png` | 전신 투명 **고해상도(4k) 원본** — 반신 크롭용 소스 |
| `full_1600.png` | 전신 1600 투명 프레이밍 |
| `half_src.png` | 반신 투명 고해상도 원본 (손 아래선까지 크롭) |
| `half_1600.png` | 반신 1600 투명 프레이밍 (옷 큼 + 양손, 좌우 ≈26%) |

> 파일명의 `1600`은 `THUMB_SIZE` 값에 따라 바뀐다. 반신은 손 잘림 회피를 위해
> 보통 `full_src.png`를 직접 크롭해 쓴다.

## 이미지 수정 방법

생성 후 일부를 고쳐야 할 때:

| 상황 | 방법 |
|------|------|
| 색·작은 디테일·합성 등 **정밀 보정** | **포토샵** — 투명 PNG를 직접 편집 (가장 정확) |
| 포켓/지퍼 위치 등 **특정 부분만 AI로 재손질** | magnific `images_generate`에 해당 이미지를 `{type:"image"}` 레퍼런스로 + "이 부분을 ~로" 편집 프롬프트 (단 다른 곳이 미세변형될 수 있어 QC 필요) |
| 얼굴·자세·전체 분위기 **크게 변경** | 재생성(`count` 늘려 후보 중 선택) |
| 같은 모델로 **다른 옷** 일관 생성 | 좋은 컷을 character 레퍼런스로 고정해 재사용 (얼굴 일관성) |

## 3단계 QC 체크리스트

생성 컷을 원본 누끼와 대조해 아래를 확인. 하나라도 틀리면 재생성 또는 보정.

- [ ] 포켓 **개수·위치** 일치
- [ ] 지퍼·지퍼풀·스트랩 등 부속 일치
- [ ] 색감·패턴(줄무늬 간격, 퀼팅 등) 일치
- [ ] 로고/라벨 위치·색 일치
- [ ] 핏·기장 왜곡 없음

### 디테일이 너무 많아 QC 불합격이 잦은 경우

- **(A)** 디테일 적은 옷만 AI 모델컷, 디테일 많은 옷은 누끼컷 그대로 사용
- **(B)** AI 생성 후 핵심 디테일만 사람이 보정하는 반자동 워크플로우
