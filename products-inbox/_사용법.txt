========================================
  상품 자동 등록 — 사용법
========================================

[ 1단계 ] 상품마다 폴더 만들기
  이 폴더(products-inbox) 안에, 상품 1개당 폴더 1개를 만듭니다.
  예)  products-inbox\스너그-부력보조복\

[ 2단계 ] 폴더 안에 파일 넣기
  - info.txt        ← 상품 정보 (옆의 "_템플릿" 폴더에서 복사해 채우세요)
  - 썸네일.jpg       ← 대표 이미지 1장  (파일명에 "썸네일" 포함)
  - 상세-1.jpg       ← 상세 이미지 (여러 장 가능, 숫자 순서대로 표시됨)
  - 상세-2.jpg
  ...

[ 3단계 ] 실행
  프로젝트 폴더의  "상품업로드.bat"  를 더블클릭하세요.
  → 이미지는 Cloudinary에, 상품정보는 DB에 자동 등록됩니다.
  → 검은 창에 "✅ 등록 완료"가 뜨면 성공입니다.

[ 4단계 ] 확인
  사이트 상품 목록 / 상세 페이지에서 확인하세요.

----------------------------------------
참고
----------------------------------------
* "_"로 시작하는 폴더(_사용법, _템플릿)는 등록되지 않습니다.
* 같은 상품명으로 다시 올리면 "덮어쓰기(수정)"됩니다. (중복 등록 아님)
* 썸네일은 자동으로 960×930·연회색 배경으로 정리됩니다.
* 가격·사이즈·색상 등 정보는 info.txt 에 반드시 적어야 합니다. (이미지만으론 등록 불가)
