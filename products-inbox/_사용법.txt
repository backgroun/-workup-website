========================================
  상품 자동 등록 — 사용법 (엑셀로 일괄 등록)
========================================

[ 준비 ] 양식 전달
  "_상품정보_양식.xlsx" 를 다른 팀에 전달해 채워 받으세요.
  (한 행 = 한 상품 / 필수 칸: 상품명, 판매가)

[ 1단계 ] 엑셀 + 이미지 폴더를 products-inbox 에 넣기
  · 받은 엑셀 저장  → 파일명 앞의 "_" 는 빼고 (예: 상품정보.xlsx)
  · 상품마다 이미지 폴더  → 폴더 이름 = 엑셀 "폴더명" 칸 (비웠으면 "상품명"과 같게)
        <폴더명>/
          대표/   ← 대표컷 1장   (파일명 자유)
          상세/   ← 상세컷 여러 장 (파일명 자유, 이름순 표시)

  예)
    products-inbox/
      상품정보.xlsx
      스너그 부력보조복/
        대표/ (그레이.jpg)
        상세/ (1.jpg, 2.jpg ...)
      카약 패들/
        대표/ ...

[ 2단계 ] 실행
  프로젝트 폴더의 "상품업로드.bat" 더블클릭
  → 엑셀의 모든 행이 한 번에 등록됩니다. (행마다 "✅" 표시)

[ 3단계 ] 사이트 목록 / 상세에서 확인

----------------------------------------
참고
----------------------------------------
* products-inbox에 엑셀이 있으면 "엑셀 방식", 없으면 "폴더별 info.txt 방식"으로 자동 동작합니다.
* "_"로 시작하는 파일/폴더(_양식·_사용법·_템플릿)와 엑셀 임시파일(~$…)은 무시됩니다.
* 같은 상품명(또는 id)으로 다시 올리면 덮어쓰기(수정)됩니다. (중복 아님)
* 이미지 폴더가 없는 행도 "정보만" 등록됩니다(이미지는 나중에 추가 가능).
* 썸네일(대표)은 자동으로 960×930·연회색 배경으로 정리됩니다.
* 색상·사이즈·주요특징처럼 여러 개는 쉼표(,) 또는 세미콜론(;)으로 구분하세요.
* 카테고리: 대/중카테고리를 적거나, 안 적으면 '소품 > 기타'로 등록됩니다.
