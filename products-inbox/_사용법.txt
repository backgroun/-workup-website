========================================
  상품 자동 등록 — 사용법 (파일명 바꿀 필요 없음)
========================================

[ 1단계 ] _템플릿 폴더를 통째로 복사
  "_템플릿" 폴더를 복사해서, 이름을 상품명으로 바꾸세요.
  예)  _템플릿  →  스너그-부력보조복

  복사하면 폴더 안에 이미 이렇게 들어 있습니다:
    스너그-부력보조복\
      info.txt          ← 상품 정보 입력
      썸네일\            ← 대표 이미지 폴더
      상세\              ← 상세 이미지 폴더

[ 2단계 ] 폴더에 파일 넣기 (파일명은 아무거나 OK)
  - info.txt   → 상품명·판매가·색상·사이즈 등 입력 (메모장으로 열기)
  - 썸네일\     → 대표 이미지 1장을 그냥 넣기 (이름 바꿀 필요 없음)
  - 상세\       → 상세 이미지들을 그냥 넣기 (여러 장, 이름순으로 표시됨)

[ 3단계 ] 실행
  프로젝트 폴더의  "상품업로드.bat"  더블클릭
  → 이미지 업로드 + 상품 등록 자동 완료 ("✅ 등록 완료" 표시)

[ 4단계 ] 사이트에서 확인

----------------------------------------
참고
----------------------------------------
* 상품을 여러 개 한 번에: 상품 폴더를 여러 개 만들어 두고 한 번만 실행하면 전부 등록됩니다.
* "_"로 시작하는 폴더(_사용법, _템플릿)는 등록되지 않습니다.
* 같은 상품명으로 다시 올리면 덮어쓰기(수정)됩니다. (중복 아님)
* 썸네일은 자동으로 960×930·연회색 배경으로 정리됩니다.
* "상세" 폴더 안 이미지의 순서가 중요하면 파일명 앞에 1, 2, 3... 을 붙이세요.
* info.txt 는 반드시 채워야 합니다. (이미지만으론 가격·사이즈를 알 수 없음)
